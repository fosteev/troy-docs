# Классы — карточки

Одна карточка на класс, единый шаблон (`warrior.md` — эталон): название и код → описание/лор → ресурс →
характеристики (старт, авто-рост, таблица 1–10, билды, экипировка) → 4 скилла с полями `ClassSkill` и промтами
`icon`/`cast` → кап уровня и XP → арт (бриф, `subject`, поля манифеста, промты всех ключевых кадров и анимаций,
чек-лист) → реализация и расхождения с кодом.

Кап уровня текущего этапа — **10**, скиллов — **4** (слоты 1 / 3 / 6 / 10).

Правило: карточка = источник правды. Изменил число здесь → правишь seed/админку и манифест в `troy-assets`,
а не наоборот. Промты в карточке — итоговые строки, ушедшие в API; шаблон, из которого они собираются, —
`troy-assets/styles/class.yaml`.

- [_template.md](_template.md) — шаблон с плейсхолдерами, бюджетами и скриптом таблицы статов
- [warrior.md](warrior.md) — Воин (арт сгенерирован как dev-класс `knight`)
- [mage.md](mage.md) — Маг (арт не сгенерирован; манифест `troy-assets/assets/classes/mage.yaml` готов)
- rogue.md — Разбойник (PLANNED)
