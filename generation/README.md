# Generation — генерация контента

Сквозные инструкции «от идеи до игры» для контента, который создаётся генерацией
(Retro Diffusion + карточки в доках + admin API). Не путать с:

- [classes/](../classes/README.md) — **карточки** классов (источник правды по числам и промтам);
- [roadmap/assets/](../roadmap/assets/README.md) — план и статус конвейера ассетов;
- `troy-assets/` (соседний репо) — сами инструменты (`gen.mjs`, `publish.mjs`) и манифесты.

| Гайд | Что покрывает |
|---|---|
| [class.md](class.md) | Новый класс целиком: карточка → манифест → спрайты/иконки/анимации → скиллы с описаниями → БД → устройство |
| mob.md (TODO) | Моб: то же, короче — профиль влево, idle/attack/hit/death, иконка-маркер; шаблон `troy-assets/styles/mob.yaml` готов, пример `assets/mobs/goblin_warrior.yaml` |
| items.md (TODO) | Предметы: иконки инвентаря (Шаг 4 конвейера) |
