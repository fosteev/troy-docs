# Групповой бой — N×N (паки мобов → кооп)

> **Статус: этап 1 в работе (взят 01.09, осознанно раньше закрытия MVP-3);
> этап 2 (кооп) — после MVP.**

Переделка боёвки из жёсткого 1v1 в состояние «бой», куда входят X игроков и Y мобов
(модель WoW). Каждый участник — игрок или моб — выбирает себе цель и наносит урон ей.
Бой заканчивается, когда мертвы все игроки, мертвы все мобы, либо все живые игроки сбежали.

## Целевая модель сессии (общая для обоих этапов)

Сессия — не `{player, monster}` ([battle-session.md](../../technical/battle-session.md)),
а две стороны со списками участников:

- у каждого участника: `hp / ресурс / effects / cast / target`;
- игроки выбирают цель сами (тап по мобу), мобам цель назначает сервер
  (этап 1 — тривиально: единственный игрок; этап 2 — простая аггро-таблица по нанесённому урону);
- конец боя: все мобы `hp ≤ 0` → VICTORY · все игроки `hp ≤ 0` → DEFEAT ·
  все живые игроки завершили побег → ESCAPE. Побег индивидуален: сбежавший выходит
  из сессии, для остальных бой продолжается;
- текущий 1v1 — частный случай этой модели (1 участник с каждой стороны).

## Ассеты: решение (зафиксировано 01.09)

Стаю **не** генерим единым спрайтом: анимации играли бы всей группой, смерть одного волка
не изобразить (нужны листы «×3/×2/×1» на каждую анимацию — комбинаторный взрыв), диффузия
не держит консистентными несколько субъектов между кадрами.

Правильно — **один спрайт-лист моба, N инстансов на клиенте**:

- рассинхрон стартового кадра idle (главное, чтобы не «дышали» синхронно), flip,
  scale 0.9–1.1, лёгкий tint;
- вожак (опционально, позже) — отдельная генерация той же морды через референс
  (RD reference images), крупнее/темнее;
- новых обязательных ассетов нет; маркер пака на карте — UI-бейдж «×N» поверх обычного.

## Оценка сложности

- **Этап 1** — умеренно-крупная: контракт + сессия/движок + UI боя + баланс,
  по объёму сопоставимо с `mvp-2/polish` целиком. Детали — в спеке.
- **Этап 2** — крупная, и в основном за счёт продуктовых решений (социальный слой,
  видимость, лут), а не кода боя.
