# P3 — Старт, результат, level-up — [x] сделано

Фаза [battle polish](./README.md) → [MVP-2](../README.md).

- Intro ~1 с: карточка моба «VS» (имя, уровень, спрайт) на фоне арены, затем
  сцена; `BattleLoading` — на этом же фоне, не голый спиннер.
- Результат: reveal лута по одному (имя, иконка, редкость), XP-бар наливается
  (`BattleCharacterSummary`), золото тикает; level-up — отдельный экран/оверлей
  с фанфарой и новыми статами.
- Поражение: таймер лока (60 с) прямо на экране результата; побег — короткий
  экран без наград.
- Журнал боя — человеческие строки с иконками скиллов.

DoD: victory/defeat/escape проходят через новые экраны; level-up показан при
`leveledUpBy > 0`; widget-тесты на три исхода; `flutter test` зелёный.

**Сделано** (troy-backend `54cc410`, `fa6745c`; troy-flutter `a5106ed`).

Бэкенд (контракт пришлось расширить — без этого экран результата нечем
наполнить):
- `BattleLootDto` += `name`, `rarity`, `iconUrl` — резолвятся одним
  `item.findMany` по id выпавшего; удалённый предмет не роняет результат
  (показываем id и `COMMON`). Гонять клиент за `GET /items` по UUID не стали.
- `BattleEndDto.character` += `expToNextLevel` (вся шкала уровня, знаменатель
  XP-бара) и `attributeGains` (дельты из уже посчитанного `applyProgression`,
  `null` без апа). Новых механик и полей БД нет.
- `AdminItemRarity` стал алиасом общего `ItemRarity`. 156 тестов, build зелёный.

Клиент:
- `BattleLoading` — та же арена, что и в бою (`_ArenaBackdrop` вынесен общим),
  поверх неё секундная карточка «кто против кого» (портрет класса, VS,
  иконка/имя/уровень моба). Играет **поверх живой сцены**, так что спрайты и
  первый снапшот прогреваются под ней, и уходит сама.
- Результат: XP наливается по своей шкале (после апа — с нуля, там персонаж и
  стоит), золото натикивает, лут выезжает по одному — иконка в рамке редкости,
  имя в цвет тира, количество. Level-up забирает экран первым; награды
  стартуют по «Дальше» (под непрозрачным оверлеем анимация всё равно не видна).
- Поражение — таймер лока тикает на экране; побег — короткий экран без наград.
- Журнал резолвит коды скиллов в имена и иконки: каталог класса поднят в
  `_BattleViewState`, он переживает арену.
- `RarityColors` переехал в `shared/theme` — красит и инвентарь, и результат.
- 195 тестов, analyze чисто.

Отклонения:
- Порядок фаз: P3 сделан раньше P2 — P2 заблокирован ассетами (см. выше).
- Свежий `dart_style` расходится с репозиторием даже на нетронутых файлах,
  поэтому `dart format` по проекту не гоняли; новый код сверен с форматтером
  на копии и ему соответствует.
- Стало заметно: Swagger-DTO `BattleStartResponseDto` в api-gateway описывает
  старый пораундовый ответ (`rounds`), хотя `POST /battle/start` давно отдаёт
  `BattleStateDto`. Не трогали — вне скоупа P3, завести отдельно.
