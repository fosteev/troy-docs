# MVP-1 — Playable Map

Цель: карта должна стать игровым экраном, а не статичной витриной.

## Продуктовый результат

Игрок видит себя на карте, видит ближайших мобов и понимает, до каких мобов можно дотянуться физически.

## Backend

- Реализовать или стабилизировать map endpoints:
  - nearby entities;
  - nearby zones;
  - distance to entity;
  - interaction radius.
- Использовать PostGIS для поиска мобов рядом.
- Кэшировать частые запросы в Redis коротким TTL.
- Не отдавать мобов, которые уже умерли или заняты чужим боем.
- Возвращать DTO, достаточный клиенту:
  - id;
  - type;
  - name;
  - level;
  - lat/lng;
  - distance;
  - canInteract.

## Flutter

- Запрашивать permission на геолокацию.
- Получать текущую позицию устройства.
- Центрировать карту на игроке.
- Слать движение на backend.
- Показывать mobs из backend вместо hardcoded markers.
- Визуально различать mobs в радиусе и вне радиуса.
- Не позволять начать бой, если `canInteract = false`.
- Показывать понятное состояние при выключенной геолокации.

## Definition of Done

- На реальном устройстве позиция игрока обновляется.
- Мобы на карте приходят с backend.
- Бой доступен только в радиусе взаимодействия.
- При выключенной геолокации пользователь не попадает в сломанный экран.
